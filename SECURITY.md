# Access and data handling

Apply least-privilege access to repository collaborators.
Grant maintainers and contributors only the permissions they need. Do not commit
passwords, tokens, private keys, `.env` files, unpublished browser-session
exports or external system credentials; use environment variables or local
untracked configuration. Git history must also be reviewed before sharing.

Before public redistribution confirm fixture-media provenance and the licenses
and notices applicable to dash.js-derived changes and all other included code.
Repository visibility does not establish redistribution rights.
